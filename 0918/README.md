1. variable = expression (변수 = 표현식)
프로그래밍에서 가장 기본이 되는 대입(Assignment) 구조입니다. 우측의 계산 결과나 값을 좌측의 변수에 담는다는 뜻입니다.

literal (상수/리터وال): 변하지 않는 고정된 값 자체를 말합니다.

예시: a = 1 (1이라는 고정된 값을 a에 넣습니다.)

variable (변수): 다른 변수에 들어있는 값을 가져와서 넣는 것입니다.

예시: a = b (b가 가지고 있던 값을 a에 복사해 넣습니다.)

operator (연산자): 사칙연산 등의 계산을 거쳐 그 결과를 넣는 것입니다.

예시: a = b + 1 (b에 1을 더한 결과를 a에 넣습니다.)

function (함수): 미리 만들어둔 기능(함수)을 실행하고, 그 결과 반환되는 값을 넣는 것입니다.

예시: a = sum(1, 2) (1과 2를 더하는 함수를 실행하고 나온 결과인 3을 a에 넣습니다.)

2. Random과 Seed 값
컴퓨터는 무작위(랜덤)를 스스로 만들지 못하고 공식으로 흉내 냅니다. 이를 의사 난수(Pseudo-Random)라고 합니다.

Seed (시드 값): 랜덤 숫자를 만들어내는 수학 공식의 시작점(기준 번호)입니다.

똑같은 시드 값을 넣으면 컴퓨터는 항상 똑같은 순서의 랜덤 값을 만들어냅니다.

보통 매번 다른 랜덤을 만들기 위해 계속 변하는 값인 현재 시간(time)을 시드로 사용합니다.

3. rand 함수의 프로토타입 (Prototype)
프로그래밍에서 프로토타입이란, 함수가 어떻게 생겼는지(어떤 데이터를 받고, 어떤 결과를 돌려주는지) 미리 알려주는 설명서(선언부)를 뜻합니다. C언어 등을 기준으로 rand 함수의 프로토타입은 보통 다음과 같습니다.

프로토타입 예시: int rand(void);

int: 함수가 실행된 후 돌려주는 결과(반환값)가 정수(integer)라는 뜻입니다.

rand: 함수의 이름입니다.

void: 함수를 실행할 때 별도로 넣어줘야 하는 입력값이 없다는 뜻입니다.

4. VBA (Visual Basic for Applications)
엑셀, 워드 같은 오피스 프로그램 속에서 동작하는 매크로 및 프로그래밍 언어입니다.

엑셀에서 버튼을 눌러 자동으로 표를 정리하거나, 반복 작업을 자동화하고 싶을 때 주로 사용합니다.

VBA에서도 위에서 배운 변수 = 표현식 구조나 랜덤 함수(Rnd)를 똑같이 사용할 수 있습니다.
