1. 인터랙티브 피아노 프로그램 (practice_piano)
주요 기능: 키보드의 1~8번 숫자 키를 누르면 해당 음계(도, 레, 미, 파, 솔, 라, 시, 도)의 소리가 컴퓨터 스피커를 통해 출력되는 프로그램입니다.

핵심 포인트: Windows 전용 라이브러리(<conio.h>, <windows.h>)를 사용하여 키보드 입력을 실시간으로 감지하고, Beep() 함수로 소리를 내며 Esc 키를 누르면 종료됩니다.

2. 옥타브별 음계 주파수 출력 프로그램 (print_frequency)
주요 기능: 1옥타브부터 6옥타브까지의 12반음(도, 도#, 레, 레# 등)의 주파수(Hz)를 계산하여 콘솔 화면에 표 형태로 깔끔하게 출력해 주는 프로그램입니다.

핵심 포인트: 수학 공식(pow)을 활용해 각 음의 정확한 주파수 값을 계산하고 보기 쉽게 정렬해 줍니다.

요약하자면:

첫 번째 코드는 키를 눌러 직접 소리를 내는 피아노 프로그램이고,

두 번째 코드는 각 옥타브별 노트의 주파수 값을 계산해서 보여주는 표 출력 프로그램입니다.
