# 샤가이 나담 (Шагайн наадам)

몽골 전통 놀이 **샤가이**(양 복사뼈)를 웹 게임으로 만든 프로젝트입니다. AI(Claude)에게 프롬프트 30개를 주어 단계적으로 개선했습니다.

### ▶ [바로 플레이하기](https://cecuboiz.github.io/GameProgramming/11.20/)

설치가 필요 없습니다. 브라우저에서 열면 바로 실행되고, 휴대폰에서도 플레이할 수 있습니다.

- 작성자: 다바수렌 세렌토그토 (2024764050)
- 과목: 게임프로그래밍
- 개발 환경: HTML · CSS · JavaScript (파일 하나, 외부 라이브러리 없음)

## 두 가지 놀이

### 1. 말 경주 (Морь уралдах)
네 동물(양, 염소, 말, 낙타) 중 하나를 고릅니다. 던질 때마다 샤가이 4개가 떨어지고, 나온 면마다 그 동물이 앞으로 나아갑니다. 양과 염소는 1칸, 잘 나오지 않는 말과 낙타는 3칸 갑니다. 고른 동물이 먼저 결승선에 들어오면 승리합니다.

### 2. 샤가이 맞히기 (Шагай таах)
양쪽 모두 샤가이 10개로 시작합니다. 매 라운드 손에 1~5개를 숨기고, 번갈아 가며 두 손의 합을 맞힙니다. 맞히면 상대가 손에 숨긴 샤가이를 가져옵니다. 샤가이 20개를 먼저 모으면 승리합니다.
- **컴퓨터와 대결**: 난이도 쉬움 · 보통 · 어려움
- **2인 대전**: 한 기기로 둘이서 번갈아 플레이 (차례가 바뀔 때 화면을 가립니다)

## 주요 기능

- 게르 문이 열리는 오프닝 애니메이션
- 몽골어 · 한국어 전환, 아바타 10종
- 샤가이가 날아가 튀는 던지기 연출, 1·2·3위 시상대
- "3, 2, 1, 펴!" 카운트다운
- 웹 오디오로 합성한 음악과 효과음 (경주: 마두금 풍의 「잘람 하르」), M 키로 음소거
- 기록과 배지, 결과 카드 이미지 저장 · 공유
- 휴대폰 세로 화면 지원 (위로 밀어서 던지기)

## 조작 방법

| 동작 | 키보드 | 휴대폰 |
|---|---|---|
| 메뉴 이동 · 선택 | 방향키(W/S) · Enter | 누르기 |
| 샤가이 던지기 · 확정 | Space · Enter | 위로 밀기 |
| 게임 설명 보기 | E | – |
| 일시 정지 · 메뉴 | Esc | ≡ 버튼 |
| 소리 켜기/끄기 | M | 소리 버튼 |
