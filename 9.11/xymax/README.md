# C언어 콘솔 방향키 이동 프로그램 (Console Arrow Key Movement)

## 📌 프로젝트 개요 (Overview)
이 프로젝트는 C언어를 사용하여 윈도우 콘솔(명령 프롬프트) 창에서 키보드 방향키를 이용해 문자('A')를 이동시키는 간단한 프로그램입니다. 게임 프로그래밍의 기초가 되는 **콘솔 좌표 제어**와 **실시간 키보드 입력 처리**를 실습하기 위해 작성되었습니다.

## 🚀 주요 기능 (Features)
* **방향키 이동:** 상(Up), 하(Down), 좌(Left), 우(Right) 방향키를 사용하여 문자를 이동시킵니다.
* **경계선 처리 (Collision Detection):** 문자가 콘솔 화면의 지정된 최대 크기(`X_MAX`, `Y_MAX`)를 벗어나지 않도록 좌표를 제한합니다.
* **실시간 입력 처리:** `엔터(Enter)`를 누르지 않아도 즉각적으로 키 입력을 반영합니다.
* **프로그램 종료:** `ESC` 키(아스키코드 27)를 누르면 프로그램이 안전하게 종료됩니다.

## 🛠️ 사용된 라이브러리 (Dependencies)
* `<stdio.h>` : 표준 입출력 (printf)
* `<conio.h>` : 콘솔 입출력 (getch 함수 사용)
* `<windows.h>` : 윈도우 API 제어 (커서 위치 이동)

## 💻 주요 함수 설명 (Key Functions)

### 1. `gotoxy(int x, int y)`
화면상의 특정 `(x, y)` 좌표로 콘솔 커서를 즉시 이동시키는 함수입니다. 
`windows.h`에서 제공하는 `SetConsoleCursorPosition` API를 활용하여 화면을 지우지 않고도 원하는 위치에 문자를 출력할 수 있게 해줍니다.

### 2. `move_arrow_key(char chr, int* x, int* y, int x_b, int y_b)`
사용자가 누른 키의 아스키코드(ASCII) 값을 판별하여 X, Y 좌표를 갱신합니다.
* **방향키 아스키코드:** 상(72), 하(80), 좌(75), 우(77)
* 포인터(`*x`, `*y`)를 사용하여 main 함수에 있는 좌표 값을 직접 수정(Call by Reference)합니다.
* `x_b`, `y_b` 값을 통해 화면 경계값을 넘지 않도록 `if` 조건문으로 제한을 두었습니다.

### 3. `getch()`
`<conio.h>`에 포함된 함수로, 사용자가 키를 누르는 즉시 버퍼를 거치지 않고 바로 문자를 반환합니다. 화면에 입력한 키가 표시되지 않아 게임 같은 실시간 조작에 적합합니다.

## 🕹️ 실행 방법 (How to Run)
1. C 컴파일러(GCC, Visual Studio 등)를 사용하여 코드를 빌드합니다.
2. 실행 후 화면에 나타난 `A` 문자를 방향키를 이용해 자유롭게 움직입니다.
3. 프로그램을 종료하려면 키보드의 `ESC` 키를 누릅니다.
