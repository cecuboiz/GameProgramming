청기백기 게임 업그레이드 (응용 8-11-1)

게임프로그래밍 과제로 만든 C 콘솔 게임입니다. 원본 코드 177줄을 분석해서 버그 9개를 찾고, 모두 21개를 업그레이드했습니다.

과목: 게임프로그래밍
개발 환경: Windows · Dev-C++ (TDM-GCC 4.9.2)
게임 방법

최대 4명이 차례로 플레이합니다. 화면의 깃발 명령을 보고, 맞는 키를 제한시간 안에 누르면 됩니다.

	올려	내려
청기 (파란 깃발)	a	z
백기 (흰 깃발)	k	m
"백기 내리지 말고 청기 내려!"처럼 두 부분으로 된 명령은 뒷부분만 따릅니다.
모든 사람이 끝나면 결과표와 우승자가 나옵니다.
실행 순서
인원수(1~4명), 문제 수(1~10개), 이름, 난이도를 입력합니다.
플레이 순서를 섞습니다.
3 · 2 · 1 카운트다운 후 게임을 시작합니다.
문제마다 O/X와 걸린 시간이 바로 나옵니다.
결과표, 우승자, 최고 기록을 보여 줍니다.
y를 누르면 다시 시작합니다.
실행 방법

Windows 전용입니다. windows.h, conio.h를 쓰기 때문입니다.

Dev-C++

src/upgraded.cpp 파일을 엽니다.
F11을 눌러 컴파일하고 실행합니다.

명령어로 실행

bash
gcc -Wall -o game src/upgraded.cpp
game.exe

소스 파일은 CP949(EUC-KR) 로 저장되어 있습니다. 콘솔에서 한글이 깨지지 않게 하려고 이렇게 했습니다. GitHub 웹에서는 한글 주석이 깨져 보일 수 있지만, Dev-C++에서 열면 정상입니다.
